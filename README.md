# React Tabs with Router

A simple application demonstrating tabs navigation using React Router.

## Features

- **Tab Navigation**: Navigate between different views using tabs.
- **Routing**: URL synchronization with React Router.
- **Clean UI**: Minimalist design.

## Tech Stack

- **React 18**
- **TypeScript**
- **React Router**
- **Vite**
- **Sass (SCSS)**

## Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/react-tabs-with-router.git
   cd react-tabs-with-router
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

## Build & Production

To generate a minified production build:

```bash
npm run build
```
